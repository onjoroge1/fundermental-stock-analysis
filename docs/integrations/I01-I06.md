# Integration release 1: I01–I06

These are planning labels (I = integration), not reserved GitHub PR numbers.
I01 was reconciled against main after PR #89; I02–I06 remain separate review
and deployment units rather than being pulled into I01 through old branch merges.

1. I01: explicit eligibility, state veto, deterministic/replayed evaluation, fail-closed v2 handoff.
2. I02: shared timestamp, instrument, snapshot, risk and execution contracts.
3. I03: event ledger, exact accounting and explicit legacy-v1 projection.
4. I04: leased worker lifecycle, fenced completion, cancellation and immutable artifacts.
5. I05: validated return series and optional pinned QuantStats reporting worker.
6. I06: owner-authenticated performance/replay view with Lightweight Charts.

No change enables LIVE, accesses brokerage accounts, creates real-money orders,
or treats preview builds as production verification. Reviewed debt/source
mappings remain intact.

Heavy integrations are optional worker dependencies, not imports in the web server startup path. Initial ledger imports are explicitly legacy simulation projections; they do not retrospectively certify v1 fills as prospective.

Release order: review I01 before the cumulative stack. Full baseline CI, PostgreSQL integration tests, optional analytics compatibility tests and browser checks must pass before promotion. Preserve original research/evidence and old portfolio IDs. No historical decision or fill is silently rewritten.
